# Bapak Hasan (sample case)

Five fictional records for a made-up patient, Bapak Hasan Pratama, 67, from Surabaya. They're written in Indonesian and made to look like real scans and photos, including a handwritten note. Every page is stamped **CONTOH / SAMPLE**.

| `3_Jantung_dr_Michael_Agu2024.jpg` | Cardiologist: fast heart rate, normal heart, a 24-hour monitor planned |
| `4_Saraf_dr_Agus_Jan2025_tulisan_tangan.jpg` | Handwritten neurologist note, with one word that can't be read |
| `5_Daftar_obat_keluarga_Feb2025.jpg` | The family's list of six medicines from three doctors |

Upload all five to a new case, with Indonesian for the family and English for the doctor. Lacuno should point out that nobody followed up the thyroid result, the heart monitor was never done, and the neurologist's worry about the blood pressure medicines. It should also flag the unreadable word without guessing it.
