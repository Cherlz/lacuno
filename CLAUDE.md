# Lacuno

Next.js app for families organising a relative's medical records. See README.md.

## Front-end work

Follow `docs/DESIGN_SYSTEM.md` for any visual change: typography, photography, layout, navigation and the pre-ship checks. Any new photo must be freely licensed, self-hosted in `public/images`, added to `src/lib/photos.ts`, and recorded in `docs/IMAGE_CREDITS.md`.

## Ground rules

- Lacuno never diagnoses, ranks causes or advises changing medicine. Keep the safety wording.
- Don't invent testimonials, statistics, partners or results.
- Run `npm run lint` and `npm run build` before pushing.
